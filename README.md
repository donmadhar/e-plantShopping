# e-plantShopping — Paradise Nursery
React shopping cart app for the Skills Network Labs final project.

## Features
- Landing page and Get Started button
- Plant catalogue grouped into three categories
- Product images, descriptions, prices and Add to Cart buttons
- Redux Toolkit cart state and dynamic navbar quantity
- Increase/decrease quantity, delete items, subtotals and grand total
- Continue Shopping and Checkout demo alert
- About Us page and responsive layout

## Run
```bash
npm install
npm run dev
```
For a production build: `npm run build`.

## GitHub Pages
Push this project to a public repository named `e-plantShopping`, enable **Settings → Pages → GitHub Actions**, then push to `main`. The included workflow builds and deploys the Vite `dist` folder. Plant photographs are loaded from Unsplash and need an internet connection.
